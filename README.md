# Terminal Color Timer

A simple console-based countdown timer with color changes as the time progresses.

## Features

- Countdown timer with minutes and seconds display.
- Color changes based on remaining time:
  - Green: More than 30 seconds remaining.
  - Yellow: Between 10 and 30 seconds remaining.
  - Red: Less than 10 seconds remaining.

## Requirements

- Python 3.x
